04Pivot ▸ Generated columns

Pivot in a few lines.

Group by one field, pivot by another, add an aggregation. The pivot columns are generated for you.

  1. 01groupBy makes the rows
  2. 02pivotBy makes the columns
  3. 03aggregationReducers fill the cells
pivot.tsx 
1<DataSource2  data={trades}3  primaryKey="id"4  groupBy={[{ field: 'sector' }]}5  pivotBy={[{ field: 'region' }]}6  aggregationReducers={{7    pnl: { field: 'pnl', initialValue: 0, reducer: (a, b) => a + b },8  }}9>10  {({ pivotColumns, pivotColumnGroups }) => (11    <InfiniteTable12      pivotColumns={pivotColumns}13      pivotColumnGroups={pivotColumnGroups}14    />15  )}16</DataSource>

Grouping rows

You can use any field available in the DataSource to do the grouping. It can even be a field that is not a column.

Note ▸

When using TypeScript, both DataSource and InfiniteTable are generic and take a DATA_TYPE parameter. The fields in that type can then be used for grouping.

grouping.tsx 
1import { InfiniteTable, DataSource } from '@infinite-table/infinite-react''@infinite-table/infinite-vue'2 3type Person = { id: string; name: string; age: number; country: string }4 5const groupBy = [{ field: 'country' }]6 7<DataSource<Person> data={people} primaryKey="id" groupBy={groupBy}>8  <InfiniteTable<Person> columns={columns} />9</DataSource>

In the example above, we're grouping by country. Specifying a field that is not in the Person type is a type error.

Simple row grouping

Customizing the group column

In groupBy.column you can use any column property, for example a custom renderValue.

group-column.tsx 
1const groupBy = [2  {3    field: 'country',4    column: {5      renderValue: ({ value }) => <>Country: {value}</>,6    },7  },8]

Grouping strategies

Multiple grouping levels can be rendered as one column per group (multi-column, the default) or as a single column (single-column). Set it with groupRenderStrategy.

PropTypeDefault
groupRenderStrategy'multi-column' | 'single-column''multi-column'
groupColumnInfiniteTableColumn | (options) => InfiniteTableColumnnone
