02 / Scale Live · rows and columns virtualized

A million rows. Go on, scroll.

You scroll an empty container sized like the content; the grid moves its header and body itself, on the same frame. The header never trails the cells, and a fast fling never shows blank rows.

Rows and columns are both virtualized: only what is on screen is ever rendered.

04 / Pivot Pivoting docs →

Pivot in a few lines.

Group by one field, pivot by another, add an aggregation. The pivot columns are generated for you.

pivot.tsx 
<DataSource  data={trades}  primaryKey="id"  groupBy={[{ field: 'sector' }]}  pivotBy={[{ field: 'region' }]}  aggregationReducers={{    pnl: {      field: 'pnl',      initialValue: 0,      reducer: (a, b) => a + b,    },  }}>  {({ pivotColumns, pivotColumnGroups }) => (    <InfiniteTable      pivotColumns={pivotColumns}      pivotColumnGroups={pivotColumnGroups}    />  )}</DataSource>

Grouping rows

View as Markdown

You can use any field available in the DataSource to do the grouping. It can even be a field that is not a column.

NOTE

When using TypeScript, both DataSource and InfiniteTable are generic and take a DATA_TYPE parameter. The fields in that type can then be used for grouping.

grouping.tsx 
import { InfiniteTable, DataSource } from '@infinite-table/infinite-react@infinite-table/infinite-vue' type Person = { id: string; name: string; age: number; country: string } const groupBy = [{ field: 'country' }] <DataSource<Person> data={people} primaryKey="id" groupBy={groupBy}>  <InfiniteTable<Person> columns={columns} /></DataSource>

In the example above, we're grouping by country. Specifying a field that is not in the Person type is a type error.

Simple row grouping

#Customizing the group column

In groupBy.column you can use any column property, for example a custom renderValue.

group-column.tsx 
const groupBy = [  {    field: 'country',    column: {      renderValue: ({ value }) => <>Country: {value}</>,    },  },]

#Grouping strategies

Multiple grouping levels can be rendered as one column per group (multi-column, the default) or as a single column (single-column). Set it with groupRenderStrategy.

PropTypeDefault
groupRenderStrategy 'multi-column' | 'single-column' 'multi-column'
groupColumn InfiniteTableColumn | (options) => InfiniteTableColumn —
