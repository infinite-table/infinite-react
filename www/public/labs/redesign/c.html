No. 04Pivoting Pivoting in the docs

Pivot in a few lines.

Group by one field, pivot by another, add an aggregation. The pivot columns are generated for you.

  1. 01
    Group the rows with groupBy
  2. 02
    Spread a field across columns with pivotBy
  3. 03
    Reduce each cell with aggregationReducers
pivot.tsx
<DataSource
  data={trades}
  primaryKey="id"
  groupBy={[{ field: 'sector' }]}
  pivotBy={[{ field: 'region' }]}
  aggregationReducers={{
    pnl: { field: 'pnl', initialValue: 0, reducer: (a, b) => a + b },
  }}
>
  {({ pivotColumns, pivotColumnGroups }) => (
    <InfiniteTable
      pivotColumns={pivotColumns}
      pivotColumnGroups={pivotColumnGroups}
    />
  )}
</DataSource>

Grouping rows

You can use any field available in the DataSource to do the grouping. It can even be a field that is not a column.

Note

When using TypeScript, both DataSource and InfiniteTable are generic and take a DATA_TYPE parameter. The fields in that type can then be used for grouping.

grouping.tsx 
import { InfiniteTable, DataSource } from '@infinite-table/infinite-react''@infinite-table/infinite-vue'

type Person = { id: string; name: string; age: number; country: string }

const groupBy = [{ field: 'country' }]

<DataSource<Person> data={people} primaryKey="id" groupBy={groupBy}>
  <InfiniteTable<Person> columns={columns} />
</DataSource>

In the example above, we're grouping by country. Specifying a field that is not in the Person type is a type error.

Customizing the group column

In groupBy.column you can use any column property, for example a custom renderValue. 

const groupBy = [
  {
    field: 'country',
    column: {
      renderValue: ({ value }) => <>Country: {value}</>,
    },
  },
]

Grouping strategies

Multiple grouping levels can be rendered as one column per group (multi-column, the default) or as a single column (single-column). Set it with groupRenderStrategy.

PropTypeDefault
groupRenderStrategy 'multi-column' | 'single-column' 'multi-column'
groupColumn InfiniteTableColumn | (options) => InfiniteTableColumn none

Aggregations

Group rows can show a value computed from the rows in the group, such as a sum or an average. You define those with aggregationReducers on the DataSource.
